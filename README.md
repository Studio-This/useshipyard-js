# useshipyard-js

> Safe, reversible environment migrations. **Coming soon.**

This package reserves the name for the JavaScript/Node distribution of
[Shipyard](https://useshipyard.io) while the engine is in active development.

```js
const { comingSoon } = require('useshipyard-js')
console.log(comingSoon()) // "useshipyard — coming soon. https://useshipyard.io"
```

Running it prints the same notice:

```sh
npx useshipyard-js
# useshipyard — coming soon. https://useshipyard.io
```
